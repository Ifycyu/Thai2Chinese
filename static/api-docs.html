API文档

词义分析 | 翻译 | 学习 | 设置 | API文档

概述

ThaiWord 提供 RESTful API，支持泰语分词、词典查询、声调分析和翻译功能。

所有API地址前缀：http://your-domain.com/api/v1

注意：部分API需要通过请求头传入配置参数，敏感信息请勿明文传输。

请求头参数

请求头 说明 示例 必需
X-Dict-API 词典API地址 https://xcxapi.seak.onxxxxxx 查询单词/分析句子
X-Translate-Endpoint 翻译API端点 https://token-plan-sgpxxxxxx 翻译功能
X-Translate-Token 认证Token tp-so9m2glxxxxxx 翻译功能
X-Translate-Model 模型名称 mimo-v2.5-pro 可选

API接口

1. 完整分析

POST /api/v1/analyze

输入泰语句子，返回分词、词义、声调分析等完整信息。

参数 类型 说明 必需
sentence string 泰语句子 是 
// 请求示例
curl -X POST "http://localhost:8082/api/v1/analyze?sentence=ไปเที่ยวตลาด" \
  -H "X-Dict-API: https://xcxapi.seak.onxxxxxx"

// 返回示例
{
  "sentence": "ไปเที่ยวตลาด",
  "words": [
    {
      "word": "ไป",
      "ipa": "pai",
      "word_class": "动词",
      "chinese": "去",
      "syllables": [...]
    }
  ]
}

2. 词典查询

GET /api/v1/dict/{word}

查询单个泰语单词的释义和声调分析。

// 请求示例
curl "http://localhost:8082/api/v1/dict/สวัสดี" \
  -H "X-Dict-API: https://xcxapi.seak.onxxxxxx"

// 返回示例
{
  "word": "สวัสดี",
  "ipa": "sawatdi",
  "chinese": "你好",
  "word_class": "感叹词",
  "syllables": [...]
}

3. 分词

POST /api/v1/split

将泰语句子拆分为单词列表。

// 请求示例
curl -X POST "http://localhost:8082/api/v1/split?sentence=ไปเที่ยวตลาด"

// 返回示例
{
  "sentence": "ไปเที่ยวตลาด",
  "words": ["ไป", "เที่ยว", "ตลาด"]
}

4. 声调分析

GET /api/v1/tone/{word}

分析泰语单词的声调（自动拆分音节）。

// 请求示例
curl "http://localhost:8082/api/v1/tone/สวัสดี"

// 返回示例
{
  "word": "สวัสดี",
  "syllables": [
    {
      "syllable": "สวัส",
      "consonant": "ส",
      "consonant_class": "high",
      "vowel": "-ั",
      "tone": {"tone": "rising", "tone_cn": "升声调", "tone_number": 5}
    }
  ]
}

5. 翻译

POST /api/v1/translate

将泰语翻译成中文（需要配置翻译API）。

// 请求示例
curl -X POST "http://localhost:8082/api/v1/translate?sentence=ไปเที่ยวตลาด" \
  -H "X-Translate-Endpoint: https://token-plan-sgpxxxxxx" \
  -H "X-Translate-Token: tp-so9m2glxxxxxx" \
  -H "X-Translate-Model: mimo-v2.5-pro"

// 返回示例
{
  "original": "ไปเที่ยวตลาด",
  "translated": "去逛市场"
}

6. 翻译

POST /api/translate

翻译泰语到中文。返回任务ID，然后轮询结果。

// 步骤1：提交任务
curl -X POST "http://localhost:8082/api/translate" \
  -H "Content-Type: application/json" \
  -H "X-Translate-Endpoint: https://token-plan-sgpxxxxxx" \
  -H "X-Translate-Token: tp-so9m2glxxxxxx" \
  -d '{"text": "ไปเที่ยวตลาด"}'

// 返回任务ID
{"task_id": "abc-123", "status": "pending"}

// 步骤2：轮询结果
curl "http://localhost:8082/api/task/abc-123"

// 返回结果
{"task_id": "abc-123", "status": "completed", "result": "去逛市场"}

7. 学习分析

POST /api/learn

学习分析泰语句子。返回任务ID，然后轮询结果。

// 提交任务
curl -X POST "http://localhost:8082/api/learn" \
  -H "Content-Type: application/json" \
  -H "X-Translate-Endpoint: https://token-plan-sgpxxxxxx" \
  -H "X-Translate-Token: tp-so9m2glxxxxxx" \
  -d '{"sentence": "สวัสดีครับ"}'

// 轮询结果
curl "http://localhost:8082/api/task/{task_id}"

Python 调用示例

使用提供的加密工具：

from encrypt_helper import make_request

BASE_URL = "http://localhost:8082/api/v1"
SECRET = "your-secret-key"

# 查询单词（自动加密）
result = make_request(
    url=f"{BASE_URL}/dict/ตลาด",
    secret=SECRET,
    dict_api="https://xcxapi.seak.onxxxxxx"
)

# 翻译（自动加密）
result = make_request(
    url=f"{BASE_URL}/translate?sentence=ไปเที่ยวตลาด",
    secret=SECRET,
    translate_endpoint="https://token-plan-sgpxxxxxx",
    translate_token="tp-so9m2glxxxxxx"
)

或使用 requests 库手动加密：

import requests
from encrypt_helper import encrypt_text

SECRET = "your-secret-key"

headers = {
    "X-Dict-API": encrypt_text("https://xcxapi.seak.onxxxxxx", SECRET),
    "X-Encrypted": "true",
}

resp = requests.get("http://localhost:8082/api/v1/dict/ตลาด", headers=headers)
print(resp.json())

加密说明

外部调用者需要自行加密敏感请求头：

  1. 使用 encrypt_helper.py 工具
  2. 设置相同的密钥（与浏览器设置中的一致）
  3. 加密后的值通过请求头传输
  4. 添加 X-Encrypted: true 请求头

加密算法：AES-GCM（256位密钥）

密钥派生：PBKDF2（100000次迭代）

JavaScript 调用示例

const BASE_URL = "/api/v1";

// 从浏览器 localStorage 读取配置
const headers = {
    "X-Dict-API": localStorage.getItem("DICT_API_URL") || "",
    "X-Translate-Endpoint": localStorage.getItem("TRANSLATE_API_ENDPOINT") || "",
    "X-Translate-Token": localStorage.getItem("TRANSLATE_AUTH_TOKEN") || "",
};

// 查询单词
fetch(`${BASE_URL}/dict/สวัสดี`, { headers })
    .then(r => r.json())
    .then(console.log);

// 分析句子
fetch(`${BASE_URL}/analyze?sentence=ไปเที่ยวตลาด`, { method: "POST", headers })
    .then(r => r.json())
    .then(console.log);
